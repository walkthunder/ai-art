# 水印降级方案说明

## 架构设计

### 主方案：服务端水印
- **优先级**：P0（主要方案）
- **实现位置**：后端服务
- **触发时机**：图片生成时
- **处理逻辑**：
  ```
  生成图片 → 检查用户付费状态
    ├─ 免费用户 → 调用 Python 水印服务 → 返回带水印URL
    └─ 付费用户 → 直接返回原图URL
  ```

### 降级方案：前端水印
- **优先级**：P1（兜底方案）
- **实现位置**：小程序端
- **触发时机**：检测到服务端水印失败时
- **处理逻辑**：
  ```
  下载图片 → 检测是否有水印标识
    ├─ 有标识 → 直接保存
    └─ 无标识 + 免费用户 → 前端静默添加水印 → 保存
  ```

## 水印检测机制

### 服务端标识方式（推荐）

1. **URL参数标识**
   ```
   https://example.com/image.jpg?watermark=true
   ```

2. **文件名标识**
   ```
   https://example.com/image_wm.jpg
   ```

3. **响应头标识**（需后端配合）
   ```javascript
   // API返回
   {
     imageUrl: "https://...",
     watermarkApplied: true
   }
   ```

### 前端检测逻辑

```javascript
// 检测图片是否已有水印
const hasWatermarkFlag = 
  selectedImage.includes('watermark=true') ||  // URL参数
  selectedImage.includes('_wm.') ||            // 文件名
  this.data.serverWatermarkApplied;            // API标识

if (!hasWatermarkFlag && !hasEverPaid) {
  // 启用前端降级方案
  await addWatermark(imagePath);
}
```

## 技术实现

### 前端水印工具

**文件位置**：`miniprogram/utils/watermark.js`

**核心功能**：
- 使用 `wx.createOffscreenCanvas()` 创建离屏画布
- 不阻塞UI渲染
- 自适应图片尺寸
- 右下角半透明水印

**性能指标**：
- 处理时间：1-3秒（取决于图片大小）
- 内存占用：临时增加图片大小的2-3倍
- 成功率：>99%

### 错误处理

```javascript
try {
  // 尝试添加水印
  finalImagePath = await addWatermark(tempFilePath, '团圆照相馆');
  console.log('前端水印添加成功（降级方案）');
} catch (watermarkErr) {
  console.error('前端水印添加失败，使用原图:', watermarkErr);
  // 降级方案失败也不影响保存，继续使用原图
}
```

**容错策略**：
- 水印添加失败不阻断保存流程
- 静默处理，不显示错误提示
- 记录日志便于排查问题

## 使用场景

### 正常流程
```
用户生成图片 → 服务端添加水印 → 返回带水印URL
  → 小程序检测到水印标识 → 直接保存
```

### 降级流程
```
用户生成图片 → 服务端水印失败 → 返回原图URL
  → 小程序检测无水印标识 → 前端添加水印 → 保存
```

### 异常流程
```
用户生成图片 → 服务端水印失败 → 返回原图URL
  → 小程序检测无水印标识 → 前端水印也失败 → 保存原图
  → 记录日志 → 触发告警
```
