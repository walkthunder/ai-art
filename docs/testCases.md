# AI全家福小程序完整测试案例集

## 📋 测试说明

### 测试环境
- **小程序版本：** v2.1.0
- **测试设备：** iOS 微信 8.0+、Android 微信 8.0+
- **测试账号：** 准备5个测试账号（新用户、免费用户、Basic付费用户、Premium付费用户、邀请用户）
- **测试数据库：** 使用测试环境数据库，避免污染生产数据

### 核心业务规则
1. **免费次数：** 新用户注册后每个模式各获得 3 次免费生成次数
2. **模式隔离：** 拼图模式和变身模式的免费次数独立计算，付费次数共享
3. **付费套餐：** 
   - Basic（尝鲜包）：¥0.01，赠送 10 次
   - Premium（尊享包）：¥29.9，赠送 35 次
4. **邀请奖励：** 邀请新用户双方各获得额外次数
5. **次数扣减：** 优先扣减免费次数，免费次数用完后扣减付费次数
